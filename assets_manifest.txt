## Indexing Notes

### How to Add Assets
1. Add the file to the appropriate directory
2. Update this manifest with file details
3. Commit both the asset and manifest update

### Naming Conventions
- Use kebab-case: `my-asset-name.png`
- Include dimensions for images: `hero-1920x1080.jpg`
- Include version for iterative designs: `mockup-v2.fig`

### Supported Formats
- **Images:** PNG, JPG, SVG, WebP
- **Videos:** MP4, WebM
- **Documents:** MD, PDF, DOCX
- **Data:** JSON, CSV, YAML
- **Design:** Figma (linked), Sketch
